Quick Start

三种形态，任选其一

纯前端本地版 · Rust 服务端 · Tauri 桌面端

terminal
# 形态一：纯前端（浏览器直连 LLM，数据存 IndexedDB）
$ pnpm install
$ pnpm dev

# 形态二：Rust 服务端（多用户、LLM 服务端代理，127.0.0.1:8787）
$ cd server && cargo run

# 形态三：Tauri 桌面端（单进程内嵌 server）
$ pnpm tauri dev

启动后：设置里添加模型服务（如火山方舟 OpenAI 兼容端点 + API Key），从人格库挑几个人格，开聊。
