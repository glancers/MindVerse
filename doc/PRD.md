# MindVerse 产品需求文档（PRD）

> 版本：v0.1.0-draft | 日期：2026-09-01 | 状态：设计阶段

## 1. 产品概述

### 1.1 一句话定位
MindVerse 是一个「AI 人格聊天室」：每个智能体拥有独立人格，用户可以像用微信一样与单个智能体私聊，也可以把多个智能体拉进一个群，看他们互相碰撞观点。

### 1.2 背景与问题
营销策划、内容创作等知识工作者经常需要「多视角碰撞」——头脑风暴、方案评审、观点交锋。传统方式是反复切换 prompt 与单个 AI 对话，视角单一、效率低、缺乏沉浸感。

### 1.3 目标用户
- 需要多视角头脑风暴的策划 / 创作者
- 想观察不同人格 AI 互动方式的爱好者
- 需要为不同场景维护多套 AI 角色设定的重度 AI 用户

### 1.4 核心价值
| 价值点 | 说明 |
| --- | --- |
| 多视角即时碰撞 | 一个群里同时存在毒舌评论家、理性分析师、乐天派，观点自动交锋 |
| 人格资产化 | 人格档案可创建、编辑、复用，跨对话保持一致 |
| 熟悉的交互 | 微信式界面，零学习成本 |
| 本地数据主权 | 聊天记录、人格、配置全存本地，可导出备份 |

## 2. 核心概念

| 概念 | 定义 |
| --- | --- |
| 人格（Persona） | 一个智能体的完整档案：名字、头像、简介、性格标签、System Prompt、绑定的模型 |
| 会话（Conversation） | 私聊（用户 ↔ 单个人格）或群聊（用户 + N 个人格） |
| Provider | 模型服务提供方（火山方舟 / OpenAI / Anthropic / 自定义 OpenAI 兼容服务） |
| 接龙（Round） | 群聊中多个智能体自动依次发言的一轮过程 |

| 群聊 | 智能体之间互相 @ | P2 |

### 3.2 人格管理

**预设人格库（P0）**
内置不少于 8 个精选人格，覆盖典型思维风格：
- 毒舌评论家（尖锐挑剔，找茬一针见血）
- 理性分析师（数据与逻辑驱动）
- 乐天派（永远乐观，善于发现机会）
- 魔鬼代言人（专门反驳主流意见）
- 用户代言人（始终站在消费者视角）
- 老板视角（关心成本、ROI、风险）
- 创意发散者（天马行空，提供脑洞）
- 冷静总结者（阶段性归纳共识与分歧）

预设人格可被编辑后另存为自己的版本，不可直接覆盖原件。

**自定义人格（P0）**
创建表单字段：
| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名字 | 是 | ≤ 20 字符 |
| 头像 | 否 | 未填则按名字自动生成色块 + 首字 |
| 简介 | 否 | 一句话人设，≤ 50 字符 |
| 性格标签 | 否 | 最多 5 个，如「毒舌」「谨慎」 |
| 人格设定（System Prompt） | 是 | 决定其说话方式与立场 |
| 绑定模型 | 否 | 默认跟随全局模型 |

**人格生成器（P1）**
用户输入一段描述（如「一个说话带东北味儿的电竞教练」），调用当前默认模型生成完整人格档案，用户确认微调后保存。

### 3.3 私聊

- 微信式对话界面：左侧人格信息，右侧气泡流
- 用户消息右对齐、AI 消息左对齐（带头像）
- 流式输出，生成中可「停止」
- P1：对最后一条 AI 回复「重新生成」

### 3.3.1 AI 助手（2026-09-05 已实现）

- 未选中会话的欢迎页为 Codex 式布局：上半部产品介绍（slogan + 私聊/群聊/AI 助手特性点），下半部居中输入卡片
- 欢迎页输入框直接发送即创建/复用唯一的「AI 助手」会话：无人格、直连全局默认模型，无需先选人格
- Enter 发送 / Shift+Enter 换行 / cmd+A 全选；未配置模型服务时显示「添加模型服务」引导

### 3.4 群聊

**建群**
- 选择 ≥ 2 个人格 + 群名（默认「XX、YY 和我的群」）
- 群成员可随时增删

**发言机制（混合模式）**
1. **@点名（默认）**：消息中 `@人格名`，被点名者依次回复（按 @ 出现顺序）；无人被 @ 时，群内默认主机智体（可设置）回复。
2. **接龙模式**：用户点击「让大家聊聊」按钮（可设轮数，默认 3 轮 / 上限 10 轮），智能体按成员顺序自动轮流发言。过程中：
   - 用户可随时「停止接龙」
   - 每个发言者能看到之前的完整上下文，且 System Prompt 中注入「当前轮到谁发言、还有谁在场」的动态信息
   - 系统为每个发言者注入人设提醒，防止人格趋同

**系统提示语（隐式）**
群聊中每条消息实际发送时附带：群名、成员列表及其人设摘要、发言历史。UI 上不展示这些注入内容。

**围观模式（P1）**
用户不发言，仅触发接龙并旁听智能体互聊。

### 3.5 设置

**Provider 管理**
- 支持添加多个 Provider：火山方舟（OpenAI 兼容）/ OpenAI / Anthropic / 自定义（Base URL + Key 的任意兼容服务）
- 每个 Provider 可配置多个模型，选定一个默认模型
- API Key 仅存本地，页面输入框做掩码显示
- 连通性测试按钮

**人格级模型覆盖**
每个人格可选「跟随全局」或指定 Provider + 模型——让不同人格用不同模型。

### 3.6 数据管理
- 第一阶段（已实现）：所有数据存 IndexedDB，可一键导出 / 导入 JSON 备份（含 API Key，本机私密迁移文件）；数据绑定访问源，开发端口固定 5175
- 第二阶段：登录后数据存服务端 SQLite（多端同步、不依赖浏览器）；未登录继续用本地模式（游客可用，双模式并存）

### 3.7 账号与多端同步（二期）

**账号体系**
- 用户名 + 密码注册 / 登录，JWT 保持登录态（30 天）
- 不做邮箱验证 / 找回密码 / 第三方登录（自部署小规模场景，保持简单；后续需要再加）
- 多用户数据完全隔离：人格、会话、消息、Provider 配置互不可见

**多端同步**
- 同一账号在多个浏览器 / 设备登录，数据一致
- P1 为拉取式同步（打开会话时增量拉取）；P2 引入实时推送
- 预设人格库为全局共享，注册即可用

**API Key 安全升级**
- Provider 的 API Key 只存服务端，浏览器不再接触明文
- 前端仅显示掩码；调用 LLM 时由服务端代为认证（顺带根治浏览器 CORS 限制）

### 3.8 皮肤主题系统（2026-09-01 已实现）

- 内置 6 套皮肤：微信绿（默认）/ 墨夜（深色）/ 蓝色幻想（深蓝）/ 樱粉 / 哥特虚空（暗紫，自带背景壁纸）/ 宣纸（米白+朱砂）
- 皮肤可自带背景壁纸（一张 16:9 壁纸铺满整窗、UI 半透明浮在其上，参考 Codex-Dream-Skin 的「氛围感」思路）；目前哥特虚空带 Gothic Void Crusade 壁纸
- 入口：设置 → 主题皮肤，迷你色板/壁纸缩略预览，点击即切换即时生效（约 300ms 平滑过渡）
- 主题选择保存在本机（localStorage），刷新不丢、首帧不闪烁；不参与多端同步（每台设备各选各的）
- 后续加皮肤只需加一组配色变量，不改组件（对创作者友好的资产化思路，参考 DreamSkin / dsh-web 的皮肤体系）

## 4. 关键用户流程

### 4.1 首次使用
1. 进入空状态引导页 → 「添加模型服务」→ 填 Base URL / API Key / 选模型 → 测试连通
2. 从预设人格库挑选人格 → 进入对话

### 4.2 多视角头脑风暴
1. 新建群 → 拉入「理性分析师」「魔鬼代言人」「创意发散者」
2. 发消息 @分析师 提问 → 得到分析
3. 点「让大家聊聊」设 3 轮 → 三人自动交锋 → 用户旁观并随时插话

## 5. 非功能需求

| 需求 | 说明 |
| --- | --- |
| 响应 | 首屏可交互 < 2s；流式输出打字机效果 |
| 数据安全 | API Key 不进浏览器（二期起只在服务端）；日志不打印 Key 内容 |
| 容错 | API 失败必须提示用户，提供重试 |
| 隐私 | 无统计埋点；自部署数据自主 |
| 部署（二期） | 单二进制 / Docker；服务器一个文件 + SQLite 数据库即可运行 |

## 6. 非目标（本期不做）
- 邮箱验证 / 找回密码 / 第三方登录
- 实时协作编辑（OT/CRDT）
- 移动端原生 App（Tauri 桌面壳为可选项）
- 智能体主动发起会话（仅在接龙中发言）
- 语音 / 图片消息
