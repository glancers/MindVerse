# MindVerse UI 设计文档（DesignSystem）

> 版本：v0.1.0-draft | 日期：2026-09-01 | 状态：设计阶段

## 1. 设计定位

「熟悉感 + 人格感」：整体骨架致敬微信（三栏/列表/气泡），视觉语言做差异化——为每个人格注入专属颜色，让对话像一场有角色的剧本围读，而非千篇一律的客服窗口。

关键词：轻快、干净、有人味。

## 2. 设计原则

1. **人格即视觉**：每个人格有专属主题色（头像底色、气泡描边、名字颜色），扫一眼就知道谁在说话
2. **信息密度克制**：一次只呈现一个焦点（正在生成的人格有明确「正在输入」指示）
3. **零学习成本**：微信用户 3 秒上手，功能藏在熟悉的位置
4. **全部 SVG 图标**，禁用 emoji；关闭按钮统一「×」字符

## 3. 布局

### 3.1 主界面（桌面优先，≥ 1024px）

```
┌────────────────────────────────────────────────────────┐
│ ┌──────────┐ ┌──────────────────────────────────────┐ │
│ │  导航栏   │ │                                      │ │
│ │  (聊天/   │ │            聊天窗口                    │ │
│ │  人格库)  │ │                                      │ │
│ ├──────────┤ │  ┌────────────────────────────┐      │ │
│ │  会话列表  │ │  │        消息气泡流           │      │ │
│ │          │ │  │                            │      │ │
│ │ [私聊]xx  │ │  │  💭 → （SVG 头像 + 气泡）     │      │ │
│ │ [群]xxx   │ │  │                            │      │ │
│ │          │ │  └────────────────────────────┘      │ │
│ │          │ │  ┌────────────────────────────┐      │ │
│ │ [+新会话] │ │  │  输入区（@提及 / 接龙按钮）    │      │ │
│ └──────────┘ │  └────────────────────────────┘      │ │
│              └──────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

- **导航栏 64px**：顶部 logo（SVG），底部「聊天」「人格库」「设置」三个图标入口
- **会话列表 280px**：搜索框 + 会话卡片（头像、标题、最后一条消息摘要、时间、未读小圆点）
- **聊天窗口自适应**：顶部会话信息栏（48px）、中部消息流（滚动）、底部输入区

### 3.2 响应式（< 768px，P2）
导航栏收为底部 Tab；会话列表与聊天窗口互斥切换。

## 4. 色彩与皮肤主题系统

### 4.1 主题变量体系（2026-09-01 落地）

全部 UI 颜色收敛为 `--mv-*` CSS 变量，挂在 `html[data-theme]` 上；Tailwind v4 通过 `@theme inline` 映射为工具类（`bg-mv-bg` / `text-mv-ink` / `border-mv-border` 等），组件零硬编码色值。切换皮肤 = 换 `data-theme` 属性，300ms 全局色彩渐变过渡。

| 变量 | 用途 |
| --- | --- |
| `--mv-bg` | 聊天区/内容区背景 |
| `--mv-rail` / `--mv-rail-hover` / `--mv-rail-active` | 导航栏+侧栏底色 / 列表 hover / 选中 |
| `--mv-panel` / `--mv-hover` | 面板/弹窗/输入框底 / 面板内 hover |
| `--mv-border` / `--mv-divider` | 边框 / 时间分隔条底 |
| `--mv-accent` / `--mv-accent-hover` / `--mv-accent-soft` | 强调色（发送、选中、活跃态）/ hover / 浅底 |
| `--mv-bubble-me(-ink)` / `--mv-bubble-other(-ink)` | 双方气泡底色与文字色 |
| `--mv-ink` / `-3` / `-4` / `-5` | 文字四级灰阶（主/次/弱/占位） |
| `--mv-link` / `--mv-link-soft` | 操作蓝（主按钮、链接、focus 描边）/ 浅底 |
| `--mv-self` | 「我」头像底色 |
| `--mv-logo-from` / `--mv-logo-to` | Logo 渐变 |

危险色 `#E5484D` 全主题统一，不设变量。

### 4.2 内置皮肤（6 套）

| 皮肤 | id | 风格 | 强调色 | 壁纸 |
| --- | --- | --- | --- | --- |
| 微信绿（默认） | `classic` | 经典绿白 | `#07C160` | - |
| 墨夜 | `midnight` | 深色夜间 | `#31C07A` | - |
| 蓝色幻想 | `bluefantasy` | 深海蓝（参考 dsh-web） | `#4C8DFF` | - |
| 樱粉 | `sakura` | 柔和粉调 | `#E46A8C` | - |
| 哥特虚空 | `gothic` | 暗紫虚空（参考 Codex-Dream-Skin） | `#A78BFA` | Gothic Void Crusade |
| 宣纸 | `paper` | 米白纸感 + 朱砂 | `#B04A3A` | - |

选择入口：设置 → 主题皮肤（迷你色板预览，点击即生效）；持久化在 localStorage `mv-theme`，首帧前 `initTheme()` 应用防闪烁。

### 4.2.1 背景壁纸机制（DreamSkin 式）

- 皮肤可自带壁纸：`--mv-bg-image`（`public/backgrounds/` 下的 URL）+ `--mv-bg-mask`（压暗蒙层，保证前景可读）；无壁纸皮肤两变量为 none，等价纯色
- 铺法：body 上 `background-image` + `cover` + `fixed`（滚动时壁纸不动，前景列表滚动）；蒙层用 `body::before`（fixed + z-index:-1）叠在壁纸之上、内容之下
- 带壁纸的皮肤把面板色改为半透明 rgba（bg/rail/panel/hover/bubble-other/border），壁纸从各层透出；蒙层透明度按壁纸明暗单独调
- 新增皮肤壁纸：图片放 `public/backgrounds/` → 皮肤块加两个变量（面板色改半透明）→ `themes.ts` 挂 `background` 元数据；组件零改动

### 4.3 人格主题色

8 个预设分配 8 色，自定义人格从色板自动取色（按名字 hash）：

| 人格 | 主题色 |
| --- | --- |
| 毒舌评论家 | `#E5484D` 红 |
| 理性分析师 | `#3B82F6` 蓝 |
| 乐天派 | `#F59E0B` 橙 |
| 魔鬼代言人 | `#8B5CF6` 紫 |
| 用户代言人 | `#10B981` 绿 |
| 老板视角 | `#64748B` 石板灰 |
| 创意发散者 | `#EC4899` 粉 |
| 冷静总结者 | `#14B8A6` 青 |

应用位置：头像底色、消息流中该人格的名字标签、群成员列表的小圆点。人格色不随皮肤切换。

### 4.4 细节打磨（随皮肤系统一并落地）

- 气泡微阴影 `0 1px 1.5px rgba(0,0,0,.05)`
- 细滚动条 6px，thumb 用 `color-mix(ink 18%~30%, transparent)` 跟随主题
- `::selection` 跟随强调色（25% 透明混合）
- 输入框 / 搜索框 focus 描边 `--mv-link`，输入区容器 `focus-within` 描边

## 5. 字体

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| display | 20/28 | 600 | 空状态标题、弹窗标题 |
| title | 15/22 | 600 | 会话标题、人格名 |
| body | 14/22 | 400 | 消息正文、表单 |
| caption | 12/18 | 400 | 时间戳、摘要、标签 |

字体族：`-apple-system, "PingFang SC", "Segoe UI", sans-serif`；消息正文 `15px`（聊天场景略大更易读）。

## 6. 核心组件规格

### 6.1 头像 Avatar（微信式圆角方形）
- 圆角 `5px`（全站统一）
- 尺寸：会话列表 44px、消息流 40px、群成员 28px
- 无图自动生成：人格主题色圆角方形 + 名字首字白字居中
- 有图：`object-fit: contain`，绝不裁切
- 用户自身头像：右侧「我」字头像（品牌蓝底白字）
- 群会话头像：田字格拼接前 4 个成员头像（白底细边框）

### 6.2 消息气泡 Bubble（微信风格）
- 用户：右对齐，微信绿 `#95EC69`，深色文字 `#111827`，圆角 8px，右上小尾巴（CSS 伪元素）
- AI：左对齐，白底无边框，圆角 8px，左上小尾巴；左侧 40px 头像
- 群聊发送者名字：灰色小字（`#7C8087`）置于气泡上方；@提及高亮保留人格主题色
- 时间分隔条：首条消息及间隔 >3 分钟时居中显示灰色小字（今天 HH:MM / 昨天 HH:MM / M月D日 HH:MM）
- 最大宽度 `min(72%, 560px)`；长文本自动换行
- 生成中：气泡尾部闪烁光标 `▍`（CSS animation）
- 失败：气泡红色 ring 描边 + 底部「重试」文字按钮
- Hover 出现操作条（小图标组）：复制 / 删除（群聊 AI 消息不带删除）

### 6.3 @提及
- 输入框键入 `@` 弹出成员选择浮层（搜索过滤），选中后插入高亮 token
- 气泡内 `@名字` 渲染为主题色加粗
- 无 @ 发送时输入框上方出现轻提示条：「未 @ 任何人，将由 {host} 回应」（可点「仍然发送」直接发）

### 6.4 输入区（微信式）
- 布局：无边框多行输入域（默认 2 行，最高 5 行）在上；下方一行左下角表情按钮（SVG Smile 22px）、右下角发送按钮
- 发送按钮：绿色 `#07C160` 圆角矩形（4px），文案「发送(S)」；输入为空时 `opacity-30` 禁用
- placeholder：「请输入消息…」（群聊为「请输入消息，@成员名 点TA发言」）
- 表情面板：10 个内置颜文字，5 列网格，点击在光标处插入；外部点击 / Esc 关闭

### 6.5 接龙控制条（群聊输入区上方）
- 生成中显示：`{当前发言者头像+名} 正在输入…` + 「停止接龙」按钮（danger 描边）
- 空闲时显示：「让大家聊聊」按钮 + 轮数步进器（1–10，默认 3）
- 接龙进行中输入框禁用（防止历史错乱），placeholder 变为「接龙进行中…」

### 6.5 弹窗与确认
- 遮罩统一 `bg-black/60 backdrop-blur-sm`
- Dialog：白底、`rounded-2xl`、顶部标题 +「×」关闭、底部按钮组（主按钮 accent，危险操作 danger）
- ConfirmDialog 经 createPortal 全局渲染，删除人格/会话/Provider 必经此组件
- 人格编辑、建群、设置均以居中 Dialog（宽 560px）呈现

### 6.6 Toast
- 顶部居中滑入，2.5s 自动消失
- 三种：success（绿点）/ error（红点）/ info（蓝点）
- API 失败、复制成功（文案：「已经复制到粘贴板」）、导入导出结果

### 6.7 表单约定
- 输入为空时提交按钮禁用态 `opacity-30`
- 所有 textarea/input 支持 cmd/ctrl+A 全选
- API Key 输入框 type=password + 「显示」切换
- 错误提示在字段下方红字 12px

### 6.8 空状态
首次进入：插画（SVG 线条风）+「添加你的第一个模型服务」主按钮 → 设置弹窗。
无人格时聊天列表区：「从人格库挑选成员开始对话」。

## 7. 动效

| 动效 | 规格 |
| --- | --- |
| 消息进入 | 气泡 translateY(8px)→0 + fade，180ms ease-out |
| 流式光标 | opacity 闪烁，600ms infinite |
| Dialog | 遮罩 fade 150ms + 面板 scale(0.96→1)，180ms |
| Toast | translateY(-12px→0)，180ms |
| 接龙轮换 | 「正在输入」名字切换时轻微 fade |

不做装饰性滚动视差，保持克制。

## 8. 无障碍
- 图标按钮均带 `aria-label`
- 对比度满足 WCAG AA（主题色用于文字时统一加深一档）
- 键盘：Esc 关闭弹窗、Enter 发送、Shift+Enter 换行、cmd/ctrl+A 全选
